# 🚀 Path Planning with Reinforcement Learning

This repository implements and compares three Reinforcement Learning (RL) algorithms—**Q-Learning**, **SARSA**, and **Deep Q-Networks (DQN)**—for grid-based path planning. The environments include static and dynamic obstacles, with agent vision and reward shaping incorporated for realistic autonomous navigation challenges.

---

## 📌 Features

- ✅ Grid-based customizable environments
- 🔁 Support for static & dynamic obstacles
- 🧠 Reinforcement Learning with:
  - Q-Learning
  - SARSA
  - DQN (Deep Q-Network)
- 🧱 Agent field of view (configurable)
- 🧭 Reward shaping based on distance from goal/start
- 📊 Performance comparison & visualization
- 📹 Real-time path and learning visualizations
